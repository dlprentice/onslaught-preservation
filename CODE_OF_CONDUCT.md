# Code of conduct

Status: active — the standard of behaviour for this repository
Last updated: 2026-11-11
Summary: this project follows the Contributor Covenant, version 2.1, and takes reports of unacceptable behaviour privately through this repository's report form or the project inbox.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone who takes part here: in issues, pull requests, reviews and any other discussion of this repository.

To report unacceptable behaviour, write to the maintainer privately through this repository's report form: open the
Security tab and choose "Report a vulnerability"
(<https://github.com/dlprentice/onslaught-preservation/security/advisories/new>). Please do not report it in a public
issue or pull request. If you would rather use email, write to the project inbox,
<onslaughtce@gmail.com>.

For how to contribute, see [CONTRIBUTING.md](CONTRIBUTING.md).
